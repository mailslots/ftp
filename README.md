# Hello Vercel

A minimal [Next.js](https://nextjs.org/) web app that displays a vibrant "Hello, Vercel!" landing page.

## Local development

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the development server

   ```bash
   npm run dev
   ```

   Visit http://localhost:3000 to see the app.

## Deploying to Vercel

This project is ready for zero-config deployment on [Vercel](https://vercel.com/):

- Import the repository into Vercel and select the `Next.js` framework preset, or
- Use the Vercel CLI:

  ```bash
  vercel deploy --prod
  ```

No additional configuration is required; the default build command (`npm run build`) and output directory (`.next`) are supported out of the box.
